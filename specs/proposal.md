## 背景

现有「网站操作模版」是 UI 操作序列，与站点页面结构强耦合、站点一改版就失效。站点功能背后几乎都有对应 HTTP 接口，把「页面操作背后的网络请求」沉淀成可复用的 API 命令，才能把「操作一个网页」变成「执行一条命令」。

## 目标

把「网站操作模版」升级为「站点 API 命令集」：更全地发现站点接口、更少约束地调用（含站点校验必需请求头）、命令集可导出导入并交付他人直接使用。

## 非目标

不做 CAPTCHA / SSO / 二次验证自动化；不做无上限自主循环与并发写操作；不新增任意 JS 执行能力；不把命令集随包分发。
